# 查看素材的原图、状态和偏移

适用：V4.3.7 源码及配套发布包。若安装的是旧版候选，请重新安装最终发布包；查看与编辑资源的区别见[补丁资源工作台](PATCH_RESOURCE_WORKBENCH.md)。

1. 打开BOO可视化编辑器并加载资源包，在左侧选择对应包标签。
2. 在素材格子上右键选择 **素材详情**；也可在列表上方输入原始 **ID**，点击 **定位**。素材列表不再显示“查看”按钮，空槽只保留透明空白缩略区域和原始编号。
3. 在查看器选择 **原图** 或 **按偏移**，再选择1×、2×、4×、8×缩放。红色十字是原点，可关闭。
4. 用棋盘、黑、白背景检查透明边缘。图片超出查看区时可以滚动，不会为了预览分配放大后的整张Canvas。
5. 展开 **详情** 查看状态、尺寸、偏移、profile、像素/alpha、压缩、数据起点和大小。未确认的字段显示“未确定”。按Escape或点击关闭返回。

“原图”模式把图像左上角放在原点；“按偏移”模式使用源资源的X/Y。四周留白只用于查看，不写回资源，也不改变NPC、ITEMSHOW或地图的绘制坐标。

## 状态与定位

- 列表计数区分槽位、有图、空槽、异常；空槽和已知损坏/不支持槽不会请求一张普通缩略图，编号保持不变。
- WIL/WZL 非零坏索引会保留为原编号的损坏或不支持项，不再作为空槽隐藏。需要重新读取以建立本轮修订的索引。
- **待解码**是打开列表时还没有结果。当前缩略图成功显示后不再挂这个提示，但不会因此伪造全包已验证。
- **读取失败**可能来自源文件变化、资源请求或解码失败，不据此直接判为文件损坏。可重新读取或到补丁管理进行[全量验证](ARCHIVE_VERIFICATION.md)。
- 多个包有相同ID时，先选包标签再定位；不自动选择其中一个。未知原始X/Y的旧GEE分支禁用“按偏移”，不把默认0冒充原值。
- 当前可见素材和详情会最多每2秒刷新一次验证状态；隐藏页面不轮询。源文件或索引发生变化时，先重新读取资源包。全包结论仍以全量验证为准。
- 该查看器不修改素材和源包；详情中的类型/标志来自标准化读取索引，不是完整原始加密头。

## 连续帧动画

1. 查看一张素材，设置 **起始ID**、**帧数**（1–240）和 **毫秒**（30–10000）。
2. 选择正向或反向，点击 **播放**；也可用 **下一帧** 逐帧检查，或 **单图** 返回原图。
3. **按偏移** 使用整组固定原点，避免每帧独立居中产生跳动。空槽、坏图和缺失ID保留在原来的帧位置，不跳号。
4. 默认 **原图 Alpha**。需要观察加亮外观时可以选择 **用户加亮（滤色）**，但这不是引擎混合公式的一致性结论。

起点、帧数、间隔、播放顺序和混合均由用户指定，不代表资源包保存了动作或八方向定义。实际脚本命令仍由对应的NPC/地图预览入口绘制。

## 进度条设置

1. 在UI编辑器点击 **进度条**，先选素材包；可输入精确数字ID或名称关键词。
2. 每页最多 100 项，通过上一页/下一页浏览。输入数字 ID 会定位到所在页并高亮，附近素材仍可见；名称关键词用于筛选。选择背景图，再切换“进度条图”选择填充素材。
3. 调整X/Y偏移，确认预览后点击 **确认使用**。预览缩放不改变保存的原始像素偏移和图片ID。
4. 关闭弹窗、切包或重新载入后，旧回调不会再修改当前设置。空槽、已确认损坏和不支持槽不能选为进度条；已恢复图片可以使用。

背景与填充必须来自同一个素材包。确认后再次打开，可直接修改偏移或再次确认；图片ID及已知素材包编号会保留。旧设置只有顶层包编号时会兼容恢复，未知编号不会自动猜成0。

## 图片、按钮、特效、关闭按钮与装备框

1. 打开对应选择器，先选素材包，再按 ID 定位或名称筛选；每页最多显示 100 项。ID 定位保留所在页的相邻素材，不缩减为单张结果。
2. 翻页不会清除已经选择的项。按钮可依次选择默认、悬停和按下图，保持同包；空槽、损坏和不支持项不能选用。
3. 确认后使用原包编号和图片 ID，不使用当前页位置。特效按输入帧数读取连续原始 ID，不用下一张有效图补位。
4. 关闭按钮、装备框和进度条的本地文件选择只更新预览，点击 **确认使用** 才保存。关闭弹窗会丢弃未确认的选择。

重新加载素材时旧选择器会关闭；请在新素材列表中重新选择。已保存的归档配置会等待相应素材包载入后恢复；同名但不同来源或存在歧义时不自动猜选。大包仍保留所有空槽编号，列表及选择器只为当前查看范围创建条目。
