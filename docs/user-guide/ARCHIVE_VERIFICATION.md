# 验证资源包的全部图片

适用：V4.3.7 源码及配套发布包中的补丁管理器，高速索引模式（PAK、JPK、WIL/WZL）。旧版安装包可能不包含这些功能。

## 操作

1. 在左侧“补”面板读取客户端补丁，选中已建立高速索引的资源包。
2. 点击该行的 **验证**。验证在独立 Worker 中逐张进行，不导出整包 PNG，不修改素材源文件。
3. 需要停止时点击 **取消**。点击 **继续验证**可复用同一源文件、同一索引代次的已完成结果；重开扩展后也可点击“验证”继续。
4. 完成或取消后点击 **详情**，打开本次 JSON 报告。需要保留报告时自行另存为。

“索引完成”只表示可以按编号读取，不表示所有图片已解码。最后的“验证完成”仍要看恢复和失败数量，不等于全部图片都正常。

## 结果含义

| 状态 | 含义 |
| --- | --- |
| 正常 / `decoded` | 此槽位成功解码为图片；有图但像素全透明也属于此项 |
| 空 / `empty` | 原索引确定为空槽，保留原编号 |
| 待验证 / `indexed-unverified` | 已有索引，但本代次尚无解码结果 |
| 恢复 / `recovered` | 在现有受限规则内恢复了压缩校验尾；不代表经过独立客户端像素验收 |
| 不支持 / `unsupported` | 已识别槽位，但其像素布局不受支持 |
| 损坏 / `corrupt` | 有结构或解码错误，不能当作空帧 |

详情里的 `failures` 包含原始 ID 与原因，最多显示 1000 条；`failuresTruncated=true` 时表示明细截断，汇总数量和磁盘逐槽状态仍完整。报告不含密码或解码密钥。

## 常见情况

- **看不到“验证”**：当前资源不是已就绪的高速索引。兼容 PNG 缓存暂不提供这一新按钮；先选择高速模式并重载该包。
- **源文件或索引已变化**：重载该包再验证。旧结果不会被新代次复用；不要手动删除其他缓存。
- **Worker、权限或缓存故障**：本次验证中止，不把尚未处理的槽位判成坏图。处理提示中的环境问题后再试。
- **状态文件损坏**：重载这一包，建立新的索引代次。原始素材及其他包的缓存不受影响。
- **详情消失**：切换引擎、重载包或重开扩展会清理界面报告；界面仅保留最近 32 份详情。逐槽结果独立持久化，重新点击“验证”即可重新核对并生成汇总。

这是读取器验证，不是自动修复或同格式重写。它不能补回截断数据，也不能证明未知历史格式或游戏中的复合绘制效果正确。报告是验证时的快照；再次读取、继续验证或打开详情时会检查源文件与索引是否仍有效。
