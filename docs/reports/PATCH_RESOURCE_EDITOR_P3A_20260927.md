## 1. 用户可用功能

- 补丁管理“素材”入口继续打开编辑区标签页，不自动浮窗。每页 100 个原始 ID，输入 ID 定位后仍保留邻项。
- 规范 GAMEOFMIR2 v2 提供开启编辑、单图替换、填空、末尾追加、清空槽位、X/Y、撤销重做、另存新包。
- 替换保留原像素布局、压缩方式、偏移及未知图块头字节。清空不移动后续 ID；未改图块按原字节复制。
- 另存对话框根据已确认家族选择 PAK/JPK 后缀，不将改后缀当作格式转换。
- JPK 既有功能与两项地图改进均包含在该候选中。地图导航图显示的是用户确认的**地点文字标记**，不是地图编号。

## 2. 可写准入与透明规则

只有 `gom-gameofmir2-v2` 可进入本轮 PAK 编辑核验。Reader 仍保持原有兼容读取规则，writer 额外要求：

1. 正确全局签名、256 字节全局头、版本 2、头后有效索引；无损坏/跳过槽。
2. 图块从索引末尾连续排列，无间隙、别名、重叠、额外尾段；所有非空图均能完整解码。
3. 仅生产 reader 已定义的 `3:0 / 5:0 / 6:0 / 6:1 / 7:0 / 7:1` 布局；zlib 不允许尾随流或尺寸不符。
4. 全局头除槽数外保留；图片头的两个未知字节保留；非编辑图块完整保留。

旧 GAMEOFMIR 没有本轮真实 writer 样本验收，不开放编辑；其他 PAK 家族不会因扩展名相同而误入。

| 布局 | 编码要求 |
| --- | --- |
| 调色板 | RGBA 必须精确存在于现有调色板 |
| RGB565 | 通道必须可按 5/6/5 位无损表达；纯黑为透明 |
| 24/32 位无 Alpha | 非黑必须不透明，纯黑必须透明；拒绝半透明、不透明纯黑及带非黑 RGB 的透明像素 |
| 24 位 + 独立 A8 / 32 位 Alpha | 保留完整 RGBA |
| 填空与追加的新槽 | 32 位 Alpha，zlib，未指定偏移时 0/0 |

导入限制沿用 P2 的受限 PNG/BMP 解码器。禁止隐式颜色量化、静默丢失 Alpha 或自动切换原槽位格式。

## 3. 保存与故障保护

保存链：检查源身份与 SHA → 同目录独占临时文件 → fsync → 生产 reader 全槽回读 → 检查槽数/空槽/头字段/像素/未改记录 → 再查源 SHA → 硬链接独占发布 → 目标再次回读 → 会话切换与索引重建。

- 只接受新文件名，不覆盖源包、已有文件、源包别名或竞争者刚创建的目标。
- 不支持硬链接的文件系统明确失败，不降级为可能暴露半文件的复制。
- 临时构建/验证失败不发布；发布后再校验失败返回“已发布但后续校验失败”，保留新文件，不伪报未保存。
- 源文件外部变化阻止操作；撤销/重做、过期 revision、页面代次和索引刷新沿用 P2 协议。
- 编辑期间导出禁用，避免误把原图当草稿；新包不自动替换正式补丁绑定。
- 保存取消、强制重启/崩溃后的草稿恢复仍未实现。
