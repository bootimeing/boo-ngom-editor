# P2 JPK 编辑与地图增量验收

日期：2026-09-27。范围：P2 第一个受限编辑闭环及用户追加的 MAP-01/MAP-02。**不是 P3–P6 或全格式完成报告。**

## 实现与取舍

JPK 编辑采用独立 TypeScript 核心与 Node Worker，复用当前 BOO 生产 reader，不复制外部 GM writer 或增加 Python/EXE 分发依赖。按 `diagnose-996pc-jpk` 的读写分离和回读门槛实施；PNG/BMP 使用明确无损子集。仅规范 GameLib/996M2 开放单张替换、填空、追加、清空、X/Y、撤销重做和另存，坏槽、尾段、间隙、重叠、未知格式标志仍只读。

修改先留在草稿；另存走同目录独占临时文件、fsync、全槽像素/元数据/空位回读、未改块字节核对、源前后 SHA、硬链接无覆盖发布和重新打开。原包与已有目标不能覆盖；保存成功切换到新包但不更改正式补丁绑定。关闭标签页保留会话并询问继续/放弃/另存；宿主恢复异常不自动丢弃草稿。
