# 素材只读查看器与虚拟列表改进

日期：2026-09-26。版本4.3.6，源码更新；没有新VSIX或安装操作。

## 已实施

- 复用现有素材虚拟列表，在每格增加“查看”，列表上方增加精确ID定位；没有再建全包PNG缓存或额外的整包像素加载。
- 计数区分槽位/图/空/异常。空槽、已知损坏与不支持槽不请求普通图片；待解码缩略图成功显示后去掉过期的待解码角标。图片请求失败显示“读取失败”，不将所有请求故障都写成文件损坏。
- 查看器提供原图/按偏移、原点、棋盘/黑/白、1×/2×/4×/8×和滚动查看。保留负偏移，不对图片按帧自动居中；仅为显示留12px边距。
- 折叠详情使用textContent显示打开时的状态、原始ID、尺寸、X/Y、profile与已有错误码。GEE legacy未解码X/Y时禁用偏移模式。其他尚未传入查看器的格式字段不猜测补值。
- 查看器为只读：隔离后方画布键盘快捷键，Escape关闭、Tab保持在对话框内；检查按钮不触发素材双击添加。
- 图片异步回调关联查看序号与素材对象；关闭、切包或替换列表后，旧结果不能重新打开查看器。悬浮预览加入同样的时序检查、离开隐藏与窗口边界限制。
- 仅使用原始图片解码结果与CSS布局缩放，不创建按8倍尺寸放大的Canvas；异常超大偏移明确提示超过预览范围。

## 验证

`tests/archive-inspector-browser.test.js`加载生产`media/editor.html`，使用真实Chrome DOM与合成事件验证：

- 10000逻辑槽位，2张图、9996空槽、2异常；虚拟窗口渲染少于200格，能精确定位9999。
- 原点与负X/正Y偏移独立，2倍像素尺寸、pixelated样式与三种背景生效。
- 空/坏槽不伪造图片，原因可读；旧GEE原始偏移未知时不提供假坐标模式。
- Escape后hidden和computed display均正确；查看时Delete不穿透到后方键盘监听。
- 关闭后旧onload、切换为较短资源列表、悬浮离开后旧onload均不产生过期预览。

第一次新UI测试发现IIFE中的新inline handler未导出，表现为点击查看后等待超时；补齐导出后原测试通过。未降低DOM断言或把函数存在性当作按钮可用证据。

最终合并回归为 **32/32**（编译、lint与30个脚本）；lint0错误、25条既有warning。证据：`artifacts/pak-hxm-layouts-20260926/tests-r4.json`，包含编辑器HTML与扩展JS哈希。`tests-r1/r2`保留PAK阶段及Edge空响应诊断；`tests-r3`保留加入SD歧义保护前的同一UI结果。

Edge 153.0.4234.48在本机headless命令中没有返回DOM；实际通过的浏览器为Chrome 153.0.8010.53。仅在无DOM时换候选，页面断言失败不重试绕过。未改变浏览器或VS Code安装。

## 仍未验收

- 本轮是浏览器DOM/合成事件测试，不是原生VS Code鼠标键盘实测或游戏客户端逐像素比较。
- 10000槽测试是合成数据，不是百万槽内存/首屏压力验收；宿主到Webview的全量元数据传输尚未改成分页。
- 列表详情仍是打开时的状态快照，尚未加入每槽验证账本实时订阅；不把图片onload当作恢复/校验状态。
- 逐图色深/alpha/压缩/物理位置的扩展详情、独立多帧锚点/方向/混合查看器及最终VSIX验收仍在总计划中。
