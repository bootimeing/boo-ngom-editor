## 发布边界

本地 VSIX 尚未替换用户已安装的扩展。开源仓库同步仅推送 `main` 源码；GitHub Actions 将在该提交上独立运行 Node 20 回归并生成 CI 产物。没有创建 `v*` 标签，因此不会触发 Marketplace 或 Open VSX 发布。远端 CI 结果应按实际提交 SHA 单独核对，不能由本地通过推断。
