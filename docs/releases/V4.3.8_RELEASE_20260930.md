# V4.3.8 变量列表稳定刷新与发布核验

日期：2026-09-30。本次在 V4.3.7 基础上修复变量列表持续刷新、内容无法稳定查看的问题，升版为 V4.3.8。旧版本记录和安装包保留，不覆盖历史验收证据。

## 使用行为

- 输入、打开或关闭文档、游戏服务器持续写入日志，不再使变量列表反复清空和重新扫描。
- 保存后合并更新；后台扫描期间保留上一次完整列表及跳转，扫描完成后再替换。变量与分组使用稳定 ID，计数改变不会改变分组身份。
- 侧栏统计已保存内容；其他文件保存时不会把尚未保存的草稿纳入结果。通用扫描器仍支持其他分析入口提供文档快照，本轮没有修改变量提取、UTAG 或个人标识规则。
- 手动刷新、M2 重载、VS Code 显式新增/删除/重命名文件及工作区切换继续更新。外部工具改动磁盘文件后，可点变量列表刷新按钮或执行 M2 重载。
- 过期扫描不发布；切换工作区立即清除旧列表；扫描异常时记录输出并保留已有列表，等待下次保存或主动刷新重试。
