## 测试可信度

首次全量测试在严格矩阵中为 201/202；单独复跑曾打印 PASS 后因 profile 清理 EPERM 退出 1。核查发现固定 profile 的旧 `DevToolsActivePort` 实际连接遗留 Edge，却被记录为当前 Chrome。该次 PASS 明确不计作有效 Chrome 验证。

测试 helper 已改为拒绝非空 profile、校验新端点与实际浏览器品牌、通过 Browser.close 关闭实际实体并有界检查端口/进程退出；两个消费者每轮新建唯一 profile。Chrome 两轮、Edge 一轮、旧 profile 拒绝、启动失败、DOM FAIL/ERROR 和显式 25 秒超时负控通过，11 个其他消费者通过。保留场景与清理的并发异常，不增加删除重试或放宽绘制断言。

本地验证使用 Windows、Node 24.14.0、Python 3.14.3，真实 Chrome/Edge 配合合成宿主或素材。CI 另使用 Node 20 / Python 3.12。浏览器与生产模块回归不代表原生 VS Code 快捷键、游戏客户端像素等价或所有用户归档格式验收。

`npm run test:all` 最终退出 0，工作区 Ctrl+F12 严格矩阵为 202/202。两项明确 SKIP：真实地图混合样本缺少当前有效 GOM/direct Objects111 索引（14954）；旧 Edge-only 表格夹具未返回 DOM。表格以显式 Chrome 替代浏览器启动、保持原断言和独立临时目录补测通过（30 DOM 行、660 单元格）；缺少的真实地图样本不计为本轮实样通过。

指定最终解包 `extension/` 为 `BOO_NPC_DIALOG_RUNTIME_ROOT` 后，严格矩阵再次 202/202 PASS、退出 0，无 SKIP。支持包根的脚本从最终包读取生产运行文件；矩阵仍包含旧 workspace-only 测试，因此不是“202 个脚本全部完全隔离”的宣称。维护者本地完整日志位于 `artifacts/release-v439-20261004`，不随 Git 提交；失败、缺样本或 SKIP 不转写为 PASS。
