# BOO 可视化编辑器 V4.3.5 / V4.3.6 更新汇总

整理日期：2026-09-27。面向用户的累计更新说明，合并同版本多轮增量，不将历史开发计划作为已交付功能。

版本口径：V4.3.5 首次版本记录为 2026-09-05，之后仍使用该版本号持续改进；V4.3.6 于 2026-09-24 升版，本汇总包含截至 2026-09-27 的最新本地组合候选。不能仅凭版本号认定早期安装包包含全部后续修复，也不代表已经发布扩展商店。

## V4.3.5

重点：完善代码到画布的本地预览、变量与条件输入、引擎语言服务、地图资源读取及 JPK 兼容。

### 1. Ctrl+F12 脚本画布

- 完善对话框、文字、按钮、输入框、菜单、列表、物品、进度条及动画的解析与本地展示。
- 静态可确定的文字和数值直接显示；无法确定的显示文字使用“预览文字”，显示数量使用 `0`。
- 完善文字绘制偏移与控件定位，传统位置参数文字按已验证的 `x-4 / y-4` 规则绘制；可逆定位的坐标支持本地微调与回写。
- 完善 ITEMSHOW 的物品读取：按数据库 IDX 查询 Looks，再定位 Items/ItemsN 素材；数量为 0 时不显示右下角数字，不把 IDX 当作图片编号。
- 改善 PLAYIMG 的帧处理和提示，保留缺失帧的时间位置，避免用下一张有效图片补位。
- 精简画布及条件区说明，保留必要的资源缺失和预览限制提示。

以上是对既有画布的持续完善。Ctrl+F12 主画布及 IDX→Looks 基础链路在 V4.3.4 已有，不应宣传为 V4.3.5 首次新增。

### 2. 变量、个人标识与条件输入

- 使用类型化预览输入：数字填数字、文字填文字，个人标识使用开关。
- 同一个个人标识合并显示，例如 `NOT CHECK [101] 0` 与 `CHECK [101] 1` 共用一个 `[101]` 输入，不重复生成两个开关。
- 自动读取当前服务端 `GlobalVal.ini` 中的全局默认值：`GlobalValN` 对应 `GN`，`GlobalStrValN` 对应 `AN`，并按引擎规则处理。
- 用户可以临时修改预览输入；保留显式 `0` 和空字符串，不修改原脚本或 GlobalVal.ini。
- 在已支持的引擎语法中提供称号、穿戴等条件输入；穿戴选项可结合数据库部位信息实现同部位互斥。
- 修正 `#IF(1)` 等条件组合的判断，按阈值而非一律“全部满足”处理。

### 3. GOTO 与数据求值

- 修复受支持的 `GOTO @数据函数` 赋值链未反映到画布的问题，静态可确定值可继续参与后续文字与数字展示。
- 扩展安全范围内的变量运算、常量显示、只读配置和数据库查询。
- 改善上古神剑、转生等脚本中“输入变化后，已知数值仍显示预览文字”的情况。
- 在确定来源和边界内补充外部页面及其同文件 GOTO helper 的只读求值；不把属性重载、发奖、扣费等服务器业务执行成预览动作。
- 补充 996PC 本地输入弹窗、STM 显示联动，以及 GOM CSVOpenCache 的显示支持。

### 4. 语言服务与开发辅助

- 更新 GOM、翎风/GEE、996PC 各自的语言数据、命令参数与相关回归，保留引擎隔离。
- 新增 `Ctrl+E` 对选区包裹 `fcolor=250`，用于快速设置文字颜色。
- 增加三引擎爆率分析及已验证的静态外部 CALL 读取，保留条件、来源和未知项。

### 5. 地图与资源读取

- 更新原始地图资源定位、缓存快照和分批枚举，减少集中扫描造成的连续阻塞。
- 完善 PAK 原生读取及自包含离线运行时。
- 修复部分 JPK 在有效索引后保留历史记录或填充数据时被误判为索引异常的问题。
- 对允许隔离的局部坏图保留原始序号，正常图片继续读取，不让后续素材编号错位。

JPK 本轮明确验证了 Mon4013、Mon4024 的相应兼容路径；Mon4028 的缺失索引恢复没有因此完成。不能将其概括为“所有 JPK 已兼容”。

## V4.3.6

重点：扩展 PAK 兼容和可诊断性，优化 UI 编辑器与素材选择，新增可安全另存的资源工作台。

### 1. PAK 兼容与读取可靠性

- 新增已验证的 HXM2/Lz V1 与 PACK4.0 分支读取，包括龙族/LZM2/LEG3、LEG/360/APPLE、KSF 对应样本。
- 统一直读、PNG 缓存、后台读取和缓存重开链路，保留原始图片编号、空槽、尺寸、偏移和透明信息。
- 继续补充有源码依据的 HXM 布局；新分支的合成测试与真实样本验收分开记录。
- 加强索引越界、相邻图块重叠、截断、压缩长度及 PNG 结构检查。
- 区分格式不支持、密码/索引不匹配、像素格式与解压错误，不再将各种错误一律提示成密码错误。
- WIL/WZL 的异常索引保留为损坏或不支持状态，不再当成空槽隐藏。

这批 HXM/PACK4 兼容曾先以 4.3.5 独立测试包验证，随后纳入 4.3.6 升版；本汇总归入 V4.3.6，避免重复统计。

### 2. 补丁验证与素材查看

- 补丁管理新增逐图验证、取消、继续验证及详情报告。
- 区分正常、空槽、待验证、恢复、不支持和损坏状态，保留失败图片 ID 与原因。
- 验证结果按源文件和索引代次保存；源包或配套索引变化后，不继续使用旧结果。
- 新增原图/按偏移查看、原点辅助线、缩放、透明背景切换及图片结构详情。
- 新增连续 ID 动画查看、正反播放、帧间隔和逐帧检查；固定公共原点，空帧与坏帧不补位。
- 优化大槽位素材目录传输和列表显示，减少大量空槽创建前端对象的开销。

### 3. UI 编辑器体验与性能

- 默认独立窗口打开，重复入口复用已有画布；不支持该能力的旧版 VS Code 可回退标签页。
- 对话框背景锁定在画布原点，不再被误拖、方向键或批量移动；普通控件仍可正常操作。
- 调整为统一深色界面、分组工具栏、紧凑素材/属性面板及主次按钮，改善窄窗口布局。
- 左上角替换为“老卢”icon.png，移除素材列表的冗余数量统计文字。
- 修复进度条设置打开卡顿，减少一次性条目创建、重复图片解码和连续输入重绘。
- 图片、按钮、特效、关闭按钮、装备框、进度条素材选择统一为每页 100 项。
- 输入素材 ID 改为定位所在页并高亮，保留邻近素材；名称输入继续用于筛选。
- 修复进度条重开后素材包编号丢失、历史 ID 恢复异常、已恢复图片误禁用及弹窗键盘穿透等问题。

### 4. 新增补丁资源工作台

- 在 VS Code 编辑区标签页内打开，不自动弹出独立窗口。
- 左侧每页 100 个槽位、每行 5 个；支持 ID 定位、跨页多选和原图/偏移查看。
- 支持 PNG 与偏移清单导出。
- 对已验证布局开放受限编辑：GameLib JPK、GAMEOFMIR2 v2 PAK，以及规范 WIL/WIX、WZL/WZX 成对资源。
- 支持单图替换、填空、追加、清空、X/Y 偏移、撤销/重做和另存新包。
- 支持按文件名 ID、连续编号或末尾追加进行批量导入；支持批量偏移、清空与跨工作台复制粘贴。
- 支持透明边裁剪并补偿偏移、最近邻缩放、镜像、Alt 拖动与方向键微调偏移。
- 支持固定原点动画、逐帧播放、参照图及无损 APNG 导出。
- 增加未保存关闭保护；批量操作预检后整体提交，失败或取消不留下半批修改。
- 按用户要求移除“新建 JPK”入口；已有包的编辑、填空和追加保留。

### 5. PAK“开启编辑”修复

- PAK 编辑复用补丁管理中已有的密码配置。
- 修复有效图片块之间存在已验证的历史未索引记录时，无法开启编辑的问题。
- 另存时保留这些历史记录的原始字节，不改变逻辑图片 ID。
- 修复失败或取消提示被后续“就绪”状态覆盖的问题，便于定位实际原因。
- 用户反馈的“<本地样本>/Data/对话框.pak”已完成相应实际文件和隔离宿主验证，源包未覆盖。

### 6. 地图与 NPC 跳转

- 修复永久 MAPEFFECT 扫描中的静态 #CALL 路径解析，优先按引擎 QuestDiary 规则查找，兼容前导反斜线；具体用户脚本是否命中仍以实际输入为准。
- 原始地图右下角导航预览增加地点文字标记、颜色和悬停提示，重复地点去重，切图清除旧标记。
- 修复 MerChant.txt 第一列引用缺失脚本时，Ctrl+左键没有创建提示的问题。
- Ctrl+点击与 Ctrl+Q 统一目标解析：按当前文档所属 Envir 定位 Market_Def，支持中文子目录、可选 `.txt` 与地图 `$` 前缀。
- 取消不创建文件/目录，确认后创建并打开，已有文件不覆盖；只悬停或查询定义不主动弹框。

## 不应写入“已完成更新”的内容

- 代码到画布并非完整游戏客户端模拟：复杂动态调用、在线玩家状态及服务器动作不能全部还原。
- 有密码不等于任意 PAK/JPK 都可读取；未知格式、缺失索引、截断数据仍有边界。
- 读取支持不等于写回支持；未验证的 PAK 分支继续只读。
- 遇到不兼容后自动同格式转换、任意跨格式整包转换、原位覆盖、崩溃后草稿恢复及 GIF 导出，未作为完成能力交付。
- 资源编辑默认另存新包；不会自动覆盖源包或替换客户端当前绑定。
- 本地模型、浏览器、扩展宿主及真实文件验证各有范围，不等于物理键鼠、原版 GM 工具箱或游戏客户端全面验收。
