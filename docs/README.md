# 文档目录

- `plans/`：架构、兼容和性能方案。
- `reports/`：已经完成的调查、审计与技术报告。
- `releases/`：扩展商店发布操作说明。
- `user-guide/`：面向最终用户的独立教程。

引擎厂商原始帮助、临时转换文件和本地研究副本不属于项目源码，不在此目录保存。
