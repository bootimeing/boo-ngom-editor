# BOO 可视化编辑器 V4.3.1

面向传奇 GM、版本制作人员和脚本开发者的一体化 Visual Studio Code 扩展。

支持 NGOM（922G/GOM）、翎风（GEE）和 996PC。将脚本开发、UI 制作、客户端资源读取、数据库维护、地图预览、脚本同步和 M2 在线重载集中在同一个工作环境中。

## 功能总览

### 传奇脚本助手

#### 多引擎语言服务

- 打开服务端目录后自动识别引擎，也可以手动切换 GOM、翎风或 996PC。
- 三个引擎分别使用独立的命令、常量、函数、补全、悬停和代码审查数据。
- 切换引擎后，脚本补全、悬停说明、语义高亮和代码审查会同步切换。
- 根据 `#IF`、`#ACT`、`#SAY` 等脚本区域提供对应类型的内容。

#### 智能补全与说明

- 支持命令、变量、标签、路径、系统常量和引擎函数智能补全。
- 支持按中文描述模糊查找指令，例如输入“检测”查找说明中包含该词的命令。
- 命令悬停可以查看用途、参数和使用方法。
- 内置常用命令、脚本片段和 `#SAY` 对话模板；`<TEXT`、`<&TEXT` 等界面指令支持补全，指令名和每个参数都可悬停查看说明。

#### 导航与引用

- 支持命令、标签和脚本路径的定义跳转与引用查找。
- `CHECKTEXTLIST`、`#CALL`、`#CALLEX`、`#INCLUDE` 等相对路径支持 `Ctrl+左键` 跳转。
- 目标脚本不存在时，可以在点击后确认创建空白文本。
- `AutoRunRobot.txt` 中的 `@函数` 可以跳转到 `RobotManage.txt` 中的对应定义。
- 支持特殊字符标签、跨文件标签、Robot 定时脚本函数和默认引擎标签。

#### 审查与快速修复

- 提供实时语法检查、问题定位和快速修复。
- 代码审查覆盖当前文件及 `MapQuest_Def`、`Market_Def`、`QuestDiary`、`Robot_def` 的脚本和子目录。
- 脚本保存后自动重新检查发生变化的文件。
- 支持查找未使用标签、脚本格式化、批量英文转大写和日志清理。

#### 编辑与显示

- 支持变量 `STR()` 包裹，多选变量或多行文本可以一次批量处理。
- 支持代码折叠、文档结构、CodeLens 和语义高亮。
- 检测命令、执行命令和 `#SAY` 界面指令分别高亮，颜色可以单独设置。
- 提供 19 套脚本主题，并支持自定义字体和语法颜色。

### 变量管理

- 自动统计整个工作区的变量、个人标识、定义位置和引用位置。
- 可分析 NPC 点击参数、变量传递、字符串拆分、列表、表格和配置文件形成的嵌套变量。
- 自动合并 `U3/u3` 等编号变量，同时保留自定义变量名的大小写语义。
- 支持搜索、分类、备注以及定义和引用位置跳转。
- 快速确认变量在哪里赋值、传递和实际使用。

### UI 可视化编辑器

- 支持图片、文字、三态按钮、特效动画、倒计时、文本框、数字框、关闭按钮、装备框和进度条。
- 支持拖动布局、属性编辑、缩放、平移、多选、复制、粘贴、删除和方向键微调。
- 支持 NPC 脚本与可视化画布双向联动，并生成对应 UI 代码。
- 支持传统 PNG 素材目录，以及 PAK、JPK、WIL、WZL 资源预览。
- WIL/WZL 当前提供只读预览，读取配套索引文件并保留原始图片序号和偏移。
- 支持同时打开多个资源包、历史记录、已缓存资源选择、单包关闭和重新读取。
- 资源标签按照 `EffectImageList.txt` 的调用顺序显示，未调用资源会提示用户。
- 保留空白图片槽位，素材名称统一显示为六位序号，避免图片位置错乱。

### 客户端与补丁管理

- 按工作区绑定传奇客户端目录，不同服务端工作区可以使用不同客户端。
- 自动识别客户端 `Data`、`Map`、`Wav`、`Graphics` 及自定义补丁目录。
- 客户端中存在多个自定义补丁时，可输入并保存当前工作区使用的补丁文件夹名，中文和英文名称均可识别。
- 同名资源优先读取自定义补丁，缺少时再读取客户端原始资源。
- 支持 GOM/翎风 PAK、WIL、WZL，以及 996PC JPK 资源。
- 支持读取需求资源或读取全部资源。日常默认只检测已调用素材、`items` 系列和 `mmap10`。
- 自动适配 `Pak.txt`、`JpkList.txt` 中的资源路径，并支持单个资源修改密码和重新读取。
- 通过文件指纹判断资源是否变化，未变化时直接复用索引，变化后重新建立索引。
- 已缓存资源由 UI 编辑器、数据库、小地图和原始地图共同使用。

### 数据库编辑器

- 支持物品、怪物和技能数据库，并按数据库类型显示对应中文属性。
- 支持 SQLite 数据库记录与字段结构的增删查改。
- 支持 Access MDB 数据库查看。
- 996PC 支持 `cfg_item.xls`、`cfg_monster.xls`、`cfg_magic.xls` 分页查看和记录增删改，写入前自动备份并保护引擎协议行。
- 大型数据库采用分页加载；横向滚动条始终可用，并固定首个数据字段至名称列，便于持续确认当前记录。
- 支持搜索、排序和装备分类筛选。选中单元格后可直接输入替换，也可双击或按 `F2` 编辑。
- 支持复制、粘贴、删除、`Ctrl+D` 填充、右下角拖拽递增，以及多选数值单元格后的右键“递增”。
- 普通修改采用原位保存以减少表格闪烁；写入失败会恢复原值，并可使用 `Ctrl+Z` 撤回上一步数据库修改。
- 右键菜单支持增加、删除、复制和粘贴数据行。
- 支持增加字段、修改字段名、删除字段和调整字段顺序。
- 物品详情显示对应素材和可视化备注，并根据 `Looks` 自动定位 `items` 至 `items9` 资源。
- 怪物详情显示怪物本体、顶戴动画和名称合成效果，并可编辑怪物爆率与顶戴配置。
- 支持普通怪物外观和 `SmartMonster` 自定义怪物配置。

数据库内置武器、衣服、头盔、项链、手镯、戒指、勋章、盾牌、腰带、靴子、宝石、时装、称号、材料、双击物品、首饰盒和神佑盒等常用分类。

### 地图查看与可视化编辑

- 地图查看器支持 `.map` 基础信息、小地图、阻挡信息、缩放和平移。
- 地图预览根据 `MapInfo.txt` 建立地图列表，并优先使用原始地图编号查找 `MiniMap.txt`。
- 支持导入小地图标识文件，编辑文字、坐标、颜色和大小地图显示范围。
- 标识可以拖动、方向键微调、增加或删除，并自动保存到原始文件。
- 每个工作区会记住标识文件路径，下次启动自动重新读取。
- 原始地图模式按照 MAP 引用的 Tiles、SmTiles 和 Objects 绘制完整地图，支持 PAK、JPK、WIL、WZL 素材。
- 原始地图首次读取显示进度，完成后缩放和平移直接复用已加载内容。
- 原始地图显示 `Merchant.txt` 中的 NPC 和 `MonGen.txt` 中的刷怪信息，不显示小地图标识编辑器。
- 可编辑 NPC 坐标、打开 NPC 脚本、编辑刷怪参数和显示刷怪范围。
- NPC、刷怪点支持拖动和方向键整数微调。
- `Merchant.txt` 中可通过 `Ctrl+左键` 点击 NPC 名称，直接定位到对应原始地图坐标。
- 原始地图提供 NPC 快速定位按钮和可展开的地图概览导航。
- 不同引擎分别使用对应的 Merchant、MonGen、NPC 外观和资源规则。

### 文件、表格与多区同步

- CSV 和常用配置表支持可视化编辑、复制、粘贴、删除、连续填充和键盘导航。
- 支持 `merchant.table`、`mongen.table` 和 Excel 97-2003 `.xls` 数据。
- 批量数值工具支持加、减、乘、除和“递增+”。
- 资源管理器可多选文件或文件夹，右键选择“同步其他区”。
- BOO 脚本助手的“快捷工具”中提供独立“脚本同步”入口。
- 双栏同步界面可以勾选当前工作区来源和同盘多个目标服务端。
- 文件夹同步会递归包含子文件和空目录，并按工作区相对路径覆盖或创建目标内容。
- 同步前显示来源数量、目标数量和写入规模，单个文件失败不会中断其余任务。

### M2 在线重载

- 保存脚本后可以自动触发 M2 重载，也支持手动重载。
- 可扫描 M2 菜单并配置不同类型脚本的重载项目。
- 内置重载组件，无需单独打开辅助工具窗口。
- 同时运行多个服务端时，按照当前工作区的 `M2Server.exe` 完整路径定向重载。
- 菜单重载无法使用时会保留明确提示，不会静默操作其他服务端进程。

### 常用辅助工具

- 代码补全编辑器与助手设置。
- 颜色代码、装备位置、StdMode 和 MapInfo 参数查询。
- 常用命令、脚本片段、脚本模板和 ANIS 特殊符号。
- 变量列表、数据库查看器和地图查看器快捷入口。
- 编辑器右上角“快捷文件”可打开常用服务端文件，并按工作区添加或移除 Mir200 相对路径。
- 左侧活动栏最下方“DeepSeek”按钮，点击后在右侧拆分编辑器打开 DeepSeek Harness AI 助手，支持自备 API Key。

## 使用方法

### 开始使用

使用 VS Code 打开传奇服务端根目录。扩展会尝试识别当前引擎；需要手动调整时，点击状态栏引擎名称或运行“BOO: 切换引擎”。

按 `Ctrl+Shift+P` 并输入“BOO”，可以查看扩展提供的全部命令。

### 使用 DeepSeek AI 助手

点击左侧活动栏最下方的“DeepSeek”按钮，扩展会在右侧拆分一个编辑器并内嵌显示本机 DeepSeek Harness；已有 Harness 实例在运行时直接复用，不会重复启动；否则自动在空闲端口启动。首次使用需先运行 DeepSeekHarness.exe（可到 QQ 交流群 58505745 下载），扩展会自动识别其安装位置。左侧栏仅保留一张迷你启动卡（可随时重新打开右侧面板）。在 Harness 设置页填入自己的 DeepSeek API Key 后即可对话。服务地址与端口可通过 boo.deepseek.host / boo.deepseek.port 调整。

### 配置客户端资源

1. 打开左侧“补丁管理”。
2. 选择传奇客户端根目录。
3. 客户端存在多个自定义补丁时，输入当前工作区使用的自定义补丁文件夹名。
4. 检查自动发现的 `Pak.txt` 或 `JpkList.txt`，必要时手动选择。
5. 日常点击“读取需求资源”；需要检查全部资源时再点击“读取所有资源”。

客户端设置按工作区保存。自定义补丁和客户端存在同名资源时，优先使用自定义补丁中的文件。

### 编写脚本

打开脚本即可使用补全、悬停、诊断、定义跳转和引用查找。中文搜索只匹配指令说明，不会因为名称相近混入其他引擎命令。

在 `#SAY` 区域输入 `<` 可以补全当前引擎支持的界面指令；鼠标悬停在 `<TEXT`、`<&TEXT` 等指令名上可查看用途和全部参数，悬停在某个参数值上只显示该参数的含义。界面指令颜色可在“BOO: 颜色设置”中单独调整。

路径引用和 Merchant NPC 名称需要按住 `Ctrl` 后单击才会跳转；仅按住 `Ctrl` 不会弹出创建提示。

点击编辑器右上角“快捷文件”可打开内置常用文件。选择“添加自定义文件”后输入相对于 `Mir200` 的路径，例如 `Envir\QuestDiary\功能脚本\示例.txt`；自定义列表按当前工作区保存，也可从同一菜单移除。

### 制作 UI

打开左侧“BOO 可视化编辑器”，从新资源、历史记录或补丁缓存中选择素材。双击素材添加到画布，随后拖动布局并在属性面板中修改参数。

PAK/JPK/WIL/WZL 会按当前引擎和服务端调用列表进行筛选。素材列表右侧的重新读取按钮可以刷新已打开资源。

### 编辑数据库

打开左侧“数据库”，选择物品、怪物或技能标签。单击数据行可查看左侧属性；选中单元格后直接输入即可替换，也可双击或按 `F2` 编辑，按 `Enter` 或点击其他单元格保存。

拖动选区右下角可以生成递增序列。多选数值单元格后右键选择“递增”并输入步长：输入 `2` 时依次增加 2、4、6，输入 `-1` 时依次减少 1、2、3。右键菜单还可新增、删除、复制或粘贴数据行，误操作可按 `Ctrl+Z` 撤回。

SQLite 可以修改字段结构；MDB 当前只读；996PC XLS 支持记录编辑，但不修改引擎协议字段结构。

### 查看地图

打开 `.map` 文件可以使用地图查看器。左侧“地图预览”用于浏览 MapInfo 地图、导入标识和切换“预览地图/原始地图”。

预览地图用于编辑小地图标识；原始地图用于查看和调整 NPC、刷怪点及真实地图素材。原始地图首次打开需要等待资源读取完成。

### 同步其他区

打开 BOO 脚本助手，在“快捷工具”中点击“脚本同步”。左侧勾选当前工作区文件或文件夹，右侧勾选一个或多个目标服务端，然后点击“开始同步”。

也可以在资源管理器中多选文件或文件夹，右键选择“同步其他区”。同步会替换目标中的同路径文件，执行前请核对确认窗口中的来源和目标。

### 配置 M2 重载

启动 M2Server 后运行 M2 菜单扫描，选择当前引擎对应的重载菜单。建议让 VS Code 与 M2 使用相同运行权限。

配置完成后，保存脚本即可自动重载，也可以通过命令面板手动执行。

## 常见问题

### 脚本中文乱码

传奇旧脚本通常使用 GB2312 或 GBK 编码。通过 VS Code 右下角编码菜单，以 GB2312 或 GBK 重新打开文件。

### 没有补全、高亮或代码审查

确认右下角语言模式为 GOM 脚本，并检查当前选择的引擎。检测命令与执行命令的颜色可以在“BOO: 颜色设置”中分别调整。

### 资源提示未调用

UI 编辑器只展示当前引擎和服务端已经调用的资源。确认资源名称已写入 `EffectImageList.txt`，然后在补丁管理或素材列表中重新读取。

### PAK/JPK 密码错误

确认当前客户端和密码文件匹配。GOM/翎风通常使用 `Pak.txt`，996PC 通常使用 `JpkList.txt`。也可以在补丁管理中为单个资源修改密码并重载。

### WIL/WZL 无法显示

确认资源与配套索引文件位于同一目录，例如 WIL/WIX 或 WZL/WZX。WIL/WZL 当前只提供预览，不修改原资源。

### 出现 `incorrect data check`

常见原因包括密码错误、文件仍在写入、复制不完整或资源包损坏。等待补丁更新完成后重新读取；固定序号持续失败时，请重新复制原始资源包。

### 物品、怪物或地图素材显示未缓存

先在补丁管理中读取需求资源。检查当前工作区绑定的客户端、自定义补丁名称和资源优先级是否正确，再重新选择数据库记录或地图。

### 数据库无法修改

MDB 当前只支持查看。SQLite 与 996PC XLS 需要写入权限，并且不能被其他数据库工具或 M2 独占。

### 原始地图没有底图

确认客户端或自定义补丁中存在 MAP 调用的 PAK/JPK/WIL/WZL，并已经在补丁管理中建立索引。自定义补丁 Map 优先于客户端 Map，最后才回退服务端 Map。

### M2 重载没有反应

确认 M2Server 正在运行，并让 VS Code 与 M2 使用相同权限。引擎更新或菜单变化后，请重新扫描 M2 菜单。

### 首次读取资源时间较长

日常使用“读取需求资源”可减少检查数量。扩展默认建立索引并按需读取单张图片，不会为整个资源包生成逐张 PNG；首次速度仍会受到资源槽位数量和磁盘性能影响。
